## 🚀 Live Demo

[AI Interview Platform](https://ai-interview-platform-aman.vercel.app/)

Developed an AI-powered interview platform that simulates real interview sessions and helps users practice technical and behavioral interviews. Built the application using Next.js, React.js, Node.js, Express.js and integrated AI-powered interview functionality. Implemented session management, API integration, authentication and transcript handling with a focus on creating a smooth and interactive user experience.
